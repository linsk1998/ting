Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

树

树控件（.tree）用于展示层级结构数据，支持节点的展开/收起和选中状态。

核心类

类描述
.tree树容器
.tree-caret展开/收起三角箭头
.tree-caret-empty空白占位（无子节点的缩进）
.tree-icon节点图标
.active选中节点
.collapse收起状态（隐藏子节点）

本项目是一个全局公用CSS库.
