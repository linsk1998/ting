Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

输入框组

标签输入框（.tags-input）用于在输入框中展示和管理多个标签，支持换行/不换行、清空、配合 input-group、标签输入、大小控制和校验反馈。
