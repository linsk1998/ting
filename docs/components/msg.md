# 提示信息

提示信息用于在操作完成后向用户反馈结果。

## 消息提示

```html
<div class="msg">
    提示提示提示
</div>
```

## 半透明提示

```html
<div class="msg msg-toast">提示提示提示</div>
```

## 消息提示带图标

```html
<div class="msg">
    <i class="msg-icon icon-lg text-success fa">&#xf058;</i>
    <span class="msg-label">测试中</span>
</div>
<div class="msg msg-toast">
    <i class="msg-icon icon-lg fa">&#xf058;</i>
    <span class="msg-label">测试中</span>
</div>
```

## 消息提示带图标垂直

```html
<div class="msg msg-vertical">
    <i class="msg-icon icon-2x text-success fa">&#xf058;</i>
    <span class="msg-label">测试中</span>
</div>
<div class="msg msg-toast msg-vertical">
    <i class="msg-icon icon-2x fa">&#xf058;</i>
    <span class="msg-label">测试中</span>
</div>
```

## 消息提示带加载图标垂直

```html
<div class="msg msg-vertical">
    <div class="msg-icon icon-2x loading-spin text-info"></div>
    <span class="msg-label">测试中</span>
</div>
<div class="msg msg-toast msg-vertical">
    <div class="msg-icon icon-2x loading-spin"></div>
    <span class="msg-label">测试中</span>
</div>
```

## 纯图标加载中

```html
<div class="msg msg-square">
    <div class="msg-icon icon-3x loading-spin text-info"></div>
</div>
<div class="msg msg-toast msg-square">
    <div class="msg-icon icon-3x loading-spin"></div>
</div>
```
