# 提示信息

提示信息用于在操作完成后向用户反馈结果，包含半透明黑底提示（`.toast`）和白色消息提示（`.msg`）两种样式。

## 半透明提示 (.toast)

```html
<div class="toast">
    恭喜提交成功！<a href="#">编辑</a>
</div>
```

## 消息提示 (.msg)

```html
<div class="msg">
    恭喜提交成功！<a href="#">编辑</a>
</div>
```

## 核心类

| 类 | 描述 |
|---|---|
| `.toast` | 半透明黑色背景提示，白色文字 |
| `.msg` | 白色背景消息提示，带边框和圆角 |
