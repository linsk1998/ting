Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

弹出框

弹出框（.popover）比工具提示包含更多内容，支持标题（.popover-header）和正文（.popover-body），可向上、右、下、左四个方向弹出。
