Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

侧栏导航

侧栏导航（.sidebar）用于构建后台管理系统的侧边导航菜单，支持亮色和暗色主题，以及折叠/展开功能。
