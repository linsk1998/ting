消息框

消息框（.msgbox）是一种特殊的对话框，左侧带有图标，适用于操作确认和状态提示。支持多种尺寸和语境色主题。

基本用法

  • 演示
  • 代码


提示标题

您确定要执行此操作吗？

<div class="msgbox">
    <div class="msgbox-header">
        <i class="fa icon-4x text-warning">&#xf06a;</i>
        <h4 class="msgbox-title">提示标题</h4>
        <a href="javascript:void 0" class="close" data-dismiss="modal"></a>
    </div>
    <div class="msgbox-body">
        <p>您确定要执行此操作吗？</p>
    </div>
    <div class="msgbox-footer">
        <button type="button" class="btn btn-default">取消</button>
        <button type="button" class="btn btn-primary">确定</button>
    </div>
</div>

核心类

类描述
.msgbox消息框容器，顶部带4px语境色边框
.msgbox-lg / .msgbox-md / .msgbox-sm尺寸
.msgbox-header头部区域
.msgbox-title标题
.msgbox-body主体内容
.msgbox-footer底部按钮区
.msgbox-info / .msgbox-success / .msgbox-warning / .msgbox-danger语境色

本项目是一个全局公用CSS库.
