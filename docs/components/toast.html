Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

提示信息

提示信息用于在操作完成后向用户反馈结果，包含半透明黑底提示（.toast）和白色消息提示（.msg）两种样式。

半透明提示 (.toast)

  • 演示
  • 代码
恭喜提交成功！编辑 
<div class="toast">
    恭喜提交成功！<a href="#">编辑</a>
</div>

消息提示 (.msg)

  • 演示
  • 代码
恭喜提交成功！编辑 
<div class="msg">
    恭喜提交成功！<a href="#">编辑</a>
</div>

核心类

类描述
.toast半透明黑色背景提示，白色文字
.msg白色背景消息提示，带边框和圆角

本项目是一个全局公用CSS库.
