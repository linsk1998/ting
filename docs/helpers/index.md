# 助手

助手类，帮助你快速完成常见的前端任务，包括浮动清除、显示隐藏、文本截断、图标、动画、加载指示等。

## 清除浮动

| 类 | 描述 |
|---|---|
| .pull-left | 元素浮动到左边 |
| .pull-right | 元素浮动到右边 |
| .clearfix | 清除容器内的浮动浮动 |

[使用方法](./float.md)

## 视觉隐藏

通过 .sr-only 类在视觉上隐藏某个元素的同时，仍然能够被辅助技术识别。

			
| 类 | 描述 |
|---|---|
| .sr-only | 在视觉上隐藏某个元素。 |

## 显示

| 类 | 描述 |
|---|---|
| .hidden-xl | 在超大屏幕隐藏 |
| .hidden-lg | 在大屏幕隐藏 |
| .hidden-md | 在中隐藏 |
| .hidden-sm | 在略小隐藏 |
| .hidden-xs | 在小隐藏 |
| .hidden | 强制元素隐藏 |
| .block | 将元素显示为block |
| .inline-block | 将元素显示为inline-block |
| .inline | 将元素显示为inline |
| .invisible | 将元素设为不可见（仍然占据体积） |
| .visible | 将元素设为可见（与invisible相对） |

## 文本截断

| 类 | 描述 |
|---|---|
| .line-{n} | 强制高度为n行，n为1~6。 |
| .line-max-{n} | 高度不得超过n行，n为1~6。 |
| .line-min-{n} | 高度不得低于n行，n为1~6。 |

## 三角标识

| 类 | 描述 |
|---|---|
| .caret | 向下三角标识，常用于下拉菜单按钮旁 |

## 关闭按钮

| 类 | 描述 |
|---|---|
| .close | 关闭按钮，显示"✕"符号，悬停变深 |

## 加载中

| 类 | 描述 |
|---|---|
| .loading-circular | 环形加载指示 |
| .loading-grow | 闪烁加载指示 |

[使用方法](./loading.md)

## 图标

| 类 | 描述 |
|---|---|
| .icon | 表示一个图标，生成一个方形inline-block。 |
| .icon-fw | 可以将图标设置为一个固定宽度。 |
| .icon-left<br/>.icon-right | 左侧的图标。右侧的图标。 |
| .icon-lg<br/>.icon-2x<br/>.icon-3x<br/>.icon-4x<br/>.icon-5x | 大字体图标。 |
| .icon-rotate-* .icon-flip-* | 对图标进行旋转和翻转 |

[使用方法](./icon.md)

## 动画

| 类 | 描述 |
|---|---|
| .animated | 动画基础类。 |
| .animated.infinite | 循环动画。 |
| .animated.forwards | 动画结束后保持最后一个帧。 |
| .animated.fast | 快速。 |
| .animated.faster | 更快。 |
| .animated.slower | 更慢。 |
[使用方法](./animation.html)
