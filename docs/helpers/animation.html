Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

动画

内置了多种 CSS3 动画效果，包括进入动画、退出动画和强调动画，可通过添加对应的类名来触发。

使用 .animated 作为动画基础类，配合具体的动画名称类即可。可以结合 .infinite（循环）、.forwards（保持结束状态）、.fast/.faster/.slower（速度控制）等修饰类使用。
