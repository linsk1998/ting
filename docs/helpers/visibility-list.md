## 显示

| 类 | 描述 |
|---|---|
| .hidden-xl | 在超大屏幕隐藏 |
| .hidden-lg | 在大屏幕隐藏 |
| .hidden-md | 在中隐藏 |
| .hidden-sm | 在略小隐藏 |
| .hidden-xs | 在小隐藏 |
| .hidden | 强制元素隐藏 |
| .block | 将元素显示为block |
| .inline-block | 将元素显示为inline-block |
| .inline | 将元素显示为inline |
| .invisible | 将元素设为不可见（仍然占据体积） |
| .visible | 将元素设为可见（与invisible相对） |
