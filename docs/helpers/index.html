Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

助手

助手类，帮助你快速完成常见的前端任务，包括浮动清除、显示隐藏、文本截断、图标、动画、加载指示等。

清除浮动

类描述
.pull-left元素浮动到左边
.pull-right元素浮动到右边
.clearfix清除容器内的浮动浮动

使用方法

视觉隐藏

通过 .sr-only 类在视觉上隐藏某个元素的同时，仍然能够被辅助技术识别。

类描述
.sr-only在视觉上隐藏某个元素。

显示

类描述
.hidden-xl在超大屏幕隐藏
.hidden-lg在大屏幕隐藏
.hidden-md在中隐藏
.hidden-sm在略小隐藏
.hidden-xs在小隐藏
.hidden强制元素隐藏
.block将元素显示为block
.inline-block将元素显示为inline-block
.inline将元素显示为inline
.invisible将元素设为不可见（仍然占据体积）
.visible将元素设为可见（与invisible相对）

文本截断

类描述
.line-{n}强制高度为n行，n为1~6。
.line-max-{n}高度不得超过n行，n为1~6。
.line-min-{n}高度不得低于n行，n为1~6。

三角标识

类描述
.caret向下三角标识，常用于下拉菜单按钮旁

关闭按钮

类描述
.close关闭按钮，显示"✕"符号，悬停变深

加载中

类描述
.loading-circular环形加载指示
.loading-grow闪烁加载指示

使用方法

图标

类描述
.icon表示一个图标，生成一个方形inline-block。
.icon-fw可以将图标设置为一个固定宽度。
.icon-left
.icon-right		左侧的图标。右侧的图标。
.icon-lg
.icon-2x
.icon-3x
.icon-4x
.icon-5x		大字体图标。
.icon-rotate-* .icon-flip-*对图标进行旋转和翻转

使用方法

动画

类描述
.animated动画基础类。
.animated.infinite循环动画。
.animated.forwards动画结束后保持最后一个帧。
.animated.fast快速。
.animated.faster更快。
.animated.slower更慢。
