# 字体

多种字体样式类，适用于标题、正文、横幅等不同场景。

- `.font-sans` 非衬线字体(黑)，通常在标题使用。
- `.font-serif` 衬线字体(宋)，通常在正文使用。
- `.font-cursive` 手写体(楷)，通常在横幅使用。
- `.font-monospace` 等宽字体，通常在代码使用。

## 非衬线字体

```html
<p class="font-sans">I need JINKELA! Africans aren't good at agricultures, we need JINKELA badly!
<br/>我要金坷垃！非洲农业不发达，必须要用金坷垃！
<br/>我要金坷垃！非洲農業不發達，必須要用金坷垃！
<br/><b>宇字</b></p>
```
