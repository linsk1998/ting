Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

排版

全局的排版设置，包括标题、段落、列表、引用、代码块等元素的样式。

标题

HTML 中的所有标题标签 <h1> 到 <h6> 均可使用。另外还提供了 .h1 到 .h6 类，为的是给内联（inline）属性的文本赋予标题的样式。

在标题内还可以包含 <small> 标签或赋予 .small 类的元素，可以用来标记副标题。

  • 代码
