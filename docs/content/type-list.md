## 文章排版

排版定义了各种标题、段落、列表及其他内联元素的样式，您可以创建标题、段落、列表及其他内联元素。

			
| 类 | 描述 |
|---|---|
| .h1~.h6 | 设置为标题样式 |
| .small、.mark | 和HTML有相同样式的class |
| .pre、.nobr | 和HTML有相同样式的class |
| .u、.s、.i、.b | 和HTML有相同样式的class |
| .text-body | 正文文本 |
| .text-muted | 减弱文本 |
| .list-unstyled | 移除默认的列表样式 |
| .list-inline<br/>.list-inline-item | 将所有列表项放置同一行 |
