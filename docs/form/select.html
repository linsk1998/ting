Ting Web UI

简洁、直观、强悍、跨浏览器的前端开发框架，让web开发更迅速、简单。

选择按钮

下拉选择按钮（.select）提供自定义样式的选择控件，支持下拉菜单、占位、置灰、加载中、错误重试等多种状态。

选择按钮的不同状态
